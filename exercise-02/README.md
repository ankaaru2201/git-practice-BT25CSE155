# Exercise 02 - Factorial Program

## Objective
Write a C++ program to calculate the factorial of a number.

## Concepts Used
- Loops
- Conditional statements
- Variables
- Basic input and output

## Compilation
g++ factorial.cpp -o factorial

## Execution
./factorial

## Sample Input
5

## Sample Output
Factorial = 120

## Conclusion
Successfully implemented a factorial program using C++.
